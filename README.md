# 최서진 — 프론트엔드 포트폴리오

Nexon 채용 담당자와 웹 플랫폼 엔지니어를 대상으로 한 독립 포트폴리오 페이지입니다. Nexon의 공식 사이트 또는 공식 포트폴리오가 아닙니다.

## 구성

- `index.html` — 시맨틱 페이지 구조, 내비게이션, 프로젝트 사례, 기술 키워드, 연락 정보, 상세 모달
- `css/style.css` — 반응형 레이아웃, 커스텀 라이트/다크 테마, 모션 및 접근성 스타일
- `js/script.js` — 모바일 메뉴, 테마 전환, 프로젝트 상세 모달, 기술 필터, 섹션 내비게이션

외부 패키지, 프레임워크, 폰트 호스팅, 이미지 서비스, 백엔드, 빌드 단계에 의존하지 않습니다. 모든 페이지 자원은 상대 경로로 연결되어 있어 저장소 루트 또는 GitHub Pages 저장소 하위 경로에서 동작하도록 구성했습니다.

프로젝트 스크린샷은 제공되지 않아 카드에는 실제 사진 대신 CSS 기반 콘셉트 패널을 사용했습니다. 실제 이미지가 준비되면 각 `.project-visual` 패널을 상대 경로 이미지로 교체할 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나, 저장소를 정적 호스팅 서비스에 올리면 됩니다. 개발 서버나 빌드는 필요하지 않습니다.

## GitHub Pages 배포

1. `index.html`, `css/`, `js/`, `assets/`, `README.md`를 GitHub 저장소 최상위에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. 배포 소스에서 `Deploy from a branch`를 선택하고 배포할 브랜치와 `/ (root)`를 지정한 뒤 저장합니다.
4. Pages가 제공하는 URL에서 페이지와 메뉴/모달/필터/테마 기능을 확인합니다.

## 제출 전 수정할 정보

이 페이지의 프로젝트 사례 및 기술 목록은 요구사항 브리프를 바탕으로 한 편집 가능한 예시입니다. 실제 수행 이력으로 오인되지 않도록 사실 확인 후 제출해야 합니다.

- `index.html`의 `최서진`, 직무명, 소개 문구를 본인 정보에 맞게 수정
- 프로젝트명, 담당 범위, 구현 기술, 문제 해결 과정과 결과를 실제 경험으로 교체
- 이벤트 허브의 **LCP 4.2초 → 1.2초**, **동시 접속 5만 명**은 검증되지 않은 예시 수치입니다. 실제 계측 결과와 측정 조건이 없으면 삭제
- Lighthouse 95점 이상 등 검증되지 않은 목표/결과는 실제 수치로 입증하거나 삭제
- `index.html`의 `[github-link-here]`, `[email-address]`, `[프로필 링크 입력]`을 실제 정보로 교체한 뒤 필요한 링크를 연결
- 기술 키워드와 숙련도 설명을 실제 경험에 맞게 업데이트

## 접근성 및 동작

키보드 건너뛰기 링크, 명시적 포커스 표시, 모바일 메뉴 상태 전달, 모달의 포커스 이동과 Escape 닫기, 필터의 `aria-pressed`, `prefers-reduced-motion` 대응을 포함합니다. 연락처는 제공된 주소가 없어 링크로 가장하지 않고 편집 가능한 플레이스홀더로 표시합니다.
